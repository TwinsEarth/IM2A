# IM2A 识别码 · 跨端 UI/交互无障碍验收清单

- 版本：v1.0（2026-10-30）
- 状态：可执行（验收用）
- 标准基线：WCAG 2.2 Level AA（含 2.2 新增 6 条：2.4.11、2.5.7、2.5.8、3.2.6、3.3.7、3.3.8）
- 上位文档：[IM2A-CODE-SERVICE-ARCHITECTURE.md](IM2A-CODE-SERVICE-ARCHITECTURE.md)（码型、状态机、错误码、TTL、统一 404）
- 范围：识别码在客户端的**展示、复制、搜索、输入、错误提示与恢复**
- 非范围：服务端实现、密码学、计费、法务结论；本文不含任何实现代码
- 交付物性质：测试用例 + 判定口径 + 证据要求；通过即代表"该端该功能对残障用户可用"，不代表"服务端正确"

## 1. 被测面、码型与测试数据

### 1.1 四个被测面

| 编号 | 被测面 | 交互形态 | 可用的无障碍手段 | 主要风险 |
|---|---|---|---|---|
| S1 | 浏览器扩展（popup / 选项页 / 名片页） | DOM，可聚焦控件 | 完整（语义、ARIA、焦点管理） | popup 尺寸小、失焦即关、屏幕阅读器难到达工具栏图标 |
| S2 | 微信 Bot（纯文本消息 + 会话命令 + 名片 H5） | 平台渲染的文本；H5 页为 DOM | 文本层可控，H5 层完整，消息层不可控 | 无按钮、无标签、长按选择、emoji 被朗读、消息分片 |
| S3 | Harness 插件 Web 面板（WorkBuddy / DSH） | 宿主 Web GUI 内的面板 | 完整，但需与宿主主题/快捷键共存 | 焦点进出面板、宿主主题对比度、快捷键冲突 |
| S4 | Harness 文本面（工具结果 / 聊天流 / CLI 输出） | 纯文本、等宽折行 | 仅文本 | 80 列折行切断码、ANSI 颜色单独表意、进度行反复朗读 |

S2 与 S4 是"不可加 ARIA"的面，验收标准因此分两类：**结构可控面**（S1/S3 + S2 的 H5）按完整 WCAG 判；**纯文本面**（S2 消息 / S4）只判"内容层可读性 + 可替代路径"，不得以"平台限制"免掉内容层要求（见 §10）。

| C1 | IM2A 号码 | 123 456 7893（3-3-4 分组） | 10 位数字 | 被读成"十二亿…"；像电话号码被自动识别为可拨打 |

## 2. 判定口径

### 2.1 三态结论

- **通过**：该条用例在声明的 AT/环境组合下全部满足期望，且证据可复核。
- **有条件通过**：主路径可用，存在等效替代路径（如"无按钮但有等价文本命令"），且替代路径本身已通过对应用例。
- **不通过**：任一 P0/P1 未满足；或"仅有替代路径但替代路径未验证"。

**整体门槛**：0 个 P0、0 个 P1 才可发布；P2 可带工单发布；P3 进常规维护。

### 2.2 严重度

| 级别 | 定义 | 典型 |
|---|---|---|
| P0 阻断 | 某类用户**无法完成**核心任务 | 屏幕阅读器拿不到码值 / 键盘无法到达复制 / 授权码无法获取或复制 |
| P1 严重 | 可完成但**需绕过**，或会**误判状态**、造成不可逆误操作 | 状态只靠颜色、错误不播报、焦点被 toast 遮挡、过期无提示 |
| P2 中等 | 明显摩擦但不影响结果 | 播报啰嗦、焦点顺序略乱、提示 3 秒消失 |
| P3 轻微 | 打磨项 | 文案措辞、朗读停顿不理想 |

### 2.3 附加项目规则（PR）

以下 4 条不属于任何单一 SC，但不满足即判不通过（评审时可引用为"项目无障碍规则 PR-x"）：

- **PR-1 码即文本**：码值必须是可选中的真实文本节点，不得是图片、Canvas、逐字拆分的装饰性元素。
- **PR-2 展示=复制=朗读**：三者指向同一字符串；任何归一化（去空格、转半角、去连字符）必须在提交前**可见地**告知，不得静默改值。
- **PR-3 状态双通道**：任何状态至少有一个**文字**通道（详见 §8）。
- **PR-4 不教用户用 AT**：不得以"请使用读屏软件的 XXX 功能"作为唯一解法；平台限制须提供平台内替代路径。

### 2.4 七个必须先定的产品决策（否则部分用例无法判定）

| 决策 | 选项 | 影响的用例 | 未定时的处理 |
|---|---|---|---|
| 是否开放公开搜索/目录 | 开放 / 不开放 | SRC-01…SRC-11 | 未定：SRC 组记"不适用（无公开搜索）"，不得记通过 |
| 复制内容保留分组还是不保留 | 复制"123 456 7893" / 复制"1234567893" | CPY-04、INP-05 | 未定：以"复制=展示"为默认判定基准 |
| Agent 子码展示是否带 "." | 带 / 改用分隔符 | DSP-05、SR-02 | 未定：按带 "." 判定，且必须逐位朗读 |
| 号码是否自动变成可点击（拨号/名片链接） | 是 / 否 | DSP-15、MOT-01 关联 | 若为是，必须明示目的（2.4.4），不得静默触发拨号 |
| 授权码是否遮蔽 | 明文 / 遮蔽+显示控件 | DSP-07、INP-09 | 未定：按明文判定（遮蔽须另过 2.2.1） |
| 微信长消息是否允许分片 | 允许 / 码整体单条 | RFW-07 | 未定：按"码必须整体一条"判定 |
| 扩展是否提供"在标签页打开" | 提供 / 不提供 | KBD-07、INV-12 | 未定：按"必须提供"判定 |

## 3. 十二条不变量（每条用例都可回溯到其中一条）

| ID | 不变量 | 违反后果 |
|---|---|---|
| INV-01 | 码是真实文本，整串一个可选中/可复制单元 | 读屏拿不到、复制残缺 → P0 |
| INV-02 | 展示串、复制串、朗读串一致；归一化必须可见 | 用户复制到错值、投诉"码无效" → P0 |
| INV-03 | 码不被任何元素切开（逐字 span、emoji、标点、分片消息） | 复制/朗读断裂 → P0 |
| INV-04 | 每个状态都有文字通道，颜色只作冗余 | 色觉障碍/高对比用户误判 → P1 |
| INV-05 | 排版不得向字符串插入视觉字符（自动断字连字符、省略号、零宽字符） | 复制出非法字符 → P0 |
| INV-06 | 授权码：只展示一次、可重新签发、无倒计时消失、不自动朗读 | 无法获取/隐私外泄 → P0 |
| INV-07 | 公开码不打码、不遮蔽（它不是凭据） | 认知障碍/读屏无法核对 → P1 |
| INV-08 | 错误必须含"原因 + 下一步"，且保留已输入内容 | 用户陷入死循环 → P1 |
| INV-09 | 焦点不被抢、不被遮挡、关闭后归还触发点 | 键盘用户迷路 → P1 |
| INV-10 | 纯文本面必须有等价文本路径（命令、纯文本消息、JSON 输出） | S2/S4 不可用 → P0 |
| INV-11 | 三端同码同形同词（分组、状态词、错误文案） | 认知负担、误操作 → P2 |
| INV-12 | 扩展 popup / 小程序式面板不得是唯一入口 | 读屏用户到不了 → P0 |

## 4. 测试环境与客观验证手法

### 4.1 环境矩阵（每端至少跑满标 ★ 的组合）

| 类别 | 组合 |
|---|---|
| 桌面读屏 ★ | NVDA（最新稳定版）+ Chrome / Firefox，Windows 11 |
| 桌面读屏（补充） | JAWS + Chrome；VoiceOver + Safari，macOS |
| 移动读屏 ★ | VoiceOver + Safari + 微信，iOS；TalkBack + Chrome + 微信，Android |
| 键盘 ★ | 全程不碰鼠标/触屏，含浏览器快捷键 |
| 缩放 ★ | 200%（1.4.4）与 400% / 320 CSS px 等效宽度（1.4.10） |
| 强制色彩 ★ | Windows 高对比主题（强制色彩）；macOS 提高对比度；Android 高对比度 |
| 文本间距 | 行高 1.5 / 字距 0.12em / 词距 0.16em / 段距 2em 覆盖后检查（1.4.12） |
| 字体放大 | iOS 更大字体（含辅助功能超大字号）；Android 字体缩放 200% |
| 颜色 | 灰度截图；protanopia / deuteranopia / tritanopia 模拟 |
| 输入 | 中文拼音、五笔；全角/半角；粘贴含换行与零宽字符 |
| 异常 | 剪贴板权限拒绝；离线；429；503；扩展被禁用剪贴板 |
| 语言 | zh-CN 与 en-US 两套语音/语言标记（3.1.1、3.1.2） |

### 4.2 六个客观手法（不依赖"我觉得能读"）

1. **听写复现法**：只开语音，测试员按听到的内容逐字输入，与原值完全一致才算通过（C1–C5 各一次）。这是判断"号码被读成数量级""子码被读成小数"的唯一可靠方法。
2. **字符计数法**：粘贴到纯文本编辑器后计数——C5 必须 34、C1 规范值 10、C3 为 10+1+n、C4 规范 12 / 展示 14；多一个空格即失败。
3. **灰度法**：截图转灰度，逐状态问"还能只凭形状/文字区分吗"。
4. **去样式法**：关闭样式后读屏浏览模式通读，状态文字若消失说明状态是 CSS 生成 → 违反 INV-04。
5. **遮挡法**：键盘走到复制按钮时触发 toast，截图看焦点指示器是否被覆盖（2.4.11）。
6. **计时法**：录屏计时，确认提示停留 ≥5 秒或可手动关闭，且消失前不打断正在朗读的内容（2.2.1）。

## 14. 清单 J · 不得用颜色单独表达状态（COL）

### 14.1 规则

**任何状态都必须至少有一个文字通道；颜色只能是第三通道。** 文字通道指：可见的状态词、可被朗读的状态（名称/描述的一部分）、或结构化的位置（分组标题"已过期"）。

### 14.2 状态决策表（逐行验收）

| 状态域 | 状态 | 允许的颜色（冗余） | 必需的非颜色通道 |
|---|---|---|---|
| 码状态 | 生效中 | 绿 | 文字"生效中" + 勾形图标 + 可播报状态 |
| | 待确认（预留） | 黄 | "待确认" + 剩余时间文字 + 沙漏图标 |
| | 已暂停 | 橙 | "已暂停" + 原因 + 恢复入口 |
| | 隔离中 | 灰 | "隔离中，X 天后可恢复" + 锁形图标 |
| | 已过期 | 灰 | "已过期" + 具体时间 |
| | 已停用 / 已吊销 | 红 | "已停用，无法解析" + 斜杠圆形图标 |
| 可用性 | 可用 / 已占用 / 保留字 / 格式非法 | — | 文字结论 + 形状不同的图标 + 下一步 |
| 复制 | 成功 / 失败 | — | "已复制" / "复制失败，已选中文本" |
| 校验 | 有效 / 无效 / 已用 / 过期 / 锁定 | — | 文字结论 + 剩余次数或时间 |
| 校验位 | 通过 / 不通过 | — | "校验位不匹配" + 位数提示 |
| 连接 | 在线 / 离线 / 重连中 | — | 文字 + 图标 + 最后更新时间 |
| 倒计时 | 充裕 / 临近 / 已过期 | — | 文字剩余时间（整分显示；最后 30 秒可逐秒显示但**不**逐秒播报） |

### 14.3 用例

| ID | 场景 | 期望 | WCAG | 级别 |
|---|---|---|---|---|
| COL-01 | 取任一状态截图转灰度 | 仅凭文字/形状即可判断 | 1.4.1 | P1 |
| COL-02 | 强制色彩模式截图 | 状态信息不丢失 | 1.4.1、1.4.11 | P1 |

## 18. 平台限制与豁免

| 限制 | 影响 | 允许的处置 |
|---|---|---|
| 微信消息层不可加语义 | 无法做标签/状态播报 | 用文本结构 + 文本命令替代；H5 页承担完整无障碍 |
| 微信长按复制不可编程 | 无"复制"按钮 | 码独占一行、前后无标点；提供"重发码"命令 |
| 扩展 popup 易失焦关闭 | 焦点与持续性受限 | 提供"在标签页打开"等价入口（INV-12） |

| 授权码 TTL（5–30 min） | 属 2.2.1"必要"例外 | 必须提前显示剩余时间文字、到期前提醒、可重新签发 |
