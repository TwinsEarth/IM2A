# ADR 0002: Pin A2A v1.0.1, keep a local adapter profile

## Status

Accepted (2026-10-29).

## Decision

- The user-facing alias "ACA" maps to the Agent2Agent (A2A) Protocol.
- Pin: protocol version `1.0`, patch release `v1.0.1`, release commit
  `3303592588e388e62e0f69f701af531d2f4e3991`.
- Source: `https://github.com/a2aproject/A2A`.
- The normative artifact is upstream `specification/a2a.proto`.
- This repository keeps a local `a2a-profile.schema.json` for adapter fields
  only; it does not re-declare the A2A standard.

## Consequences

- A2A upgrades require a new ADR/pin, not an implicit `latest`.
- Adapters validate against the local profile and cite the upstream pin.
- The full upstream proto is fetched at build time or vendored only with
  license/NOTICE review.
