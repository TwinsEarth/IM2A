# IM2A v2.3.45 Platform Monorepo (P0)

Status: **P0 scaffold only**. No release, tag, npm publish, or production deployment is created by this directory.

## Scope

This repository is the single-source home for:

- `packages/protocol`: pinned protocol schemas (A2A 1.0, MCP profile, Agent Plugins 1.0 profile, `dsh-session-ref` 1.0)
- `packages/agent-plugins`: one source bundle + multi-platform generator
- `packages/harness-adapters`: 12 harness adapter contracts
- `packages/sdk-ts`: TypeScript SDK placeholder
- `packages/ui`: shared UI placeholder
- `apps/web`, `apps/desktop`, `apps/vscode`, `apps/cli`: frontend shells
- `skills/`: declarative Agent Skills source
- `release-manifest.schema.json` + `release-manifest.json`: nine-gate release evidence
- `version-matrix.json`: platform, Go, component, and protocol targets

## Non-goals in P0

- No business UI implementation
- No production gateway changes
- No tag / GitHub Release / npm publish
- No claim that A2A is referred to as "ACA" in external docs; this repo records the user-facing alias and the official source:
  - Alias: ACA
  - Official: Agent2Agent (A2A), release `v1.0.1`, protocol version `1.0`

## Commands

```bash
npm run validate
npm test
npm run generate
npm run generate:check
```

## Release rule

The nine release gates are `commit`, `tag`, `Release`, `npm`, `CI`, `Compat`, `Release workflow`, `npm-publish`, `healthz`.
Any failing gate blocks the next gate. `release-manifest.json` must be generated by CI, not hand-edited at publish time.

## Source of truth

- Version matrix: `version-matrix.json`
- Release schema: `release-manifest.schema.json`
- Protocol pins: `packages/protocol/versions.json`
- Adapter contract: `packages/harness-adapters/src/contract.ts`
- Generator target map: `packages/agent-plugins/generator/targets.json`
