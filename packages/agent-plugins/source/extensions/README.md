# Agent Plugins extensions

This directory is the single-source location for platform extensions. P0 does
not emit platform-specific files. The generator target map is authoritative:

`../../generator/targets.json`

Targets: `dsh`, `openclaw`, `qwen-code`, `mimo-code`, `workbuddy`, `codex`,
`claude`, `gemini-cli`, `muse`, `vscode`, `copilot`, `doubao`.

Do not hand-edit generated platform directories.
